# Character art

Current character sprites are the CC0 stickman animation strips by MScull:

Source: https://opengameart.org/content/simple-animated-character-16x16
License: CC0 — public domain dedication, including commercial use.

`index.html` currently loads these four image strips directly from OpenGameArt: idle, run, jump, and roll. If you vendor the images into this directory for a fully self-contained CrazyGames build, keep the original licence/source note here and update the sprite URLs in `index.html` to local paths.
