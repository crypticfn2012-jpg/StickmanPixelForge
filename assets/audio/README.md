# Stickman Showdown audio

These are the game's local MP3 assets and are wired in `index.html`.

- `ButtonClicked.mp3` — UI button clicks
- `MainMenuMusic.mp3` — looping lobby music; starts after the first user interaction
- `Punch.mp3` — punch hit and block sound
- `kick.mp3` — kick hits
- `groundImpact.mp3` — jump, dash and landing feedback
- `death.mp3` — knockout / round-end cue

The in-game sound toggle controls both music and effects. CrazyGames' muteAudio setting takes priority.
